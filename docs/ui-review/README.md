# UI・画像・不具合修正の検証

## 変更内容

- ネイビーとゴールドの共通配色、見出し、余白、カード、フォーカス表示を整備。ホームを再設計し、PCはサイドバー、モバイルは下部ナビとメニューダイアログに統一。
- 一覧の検索・雷属性フィルター、PCの2列一覧・5列図鑑、キャラの全身／肖像表示、主人公選択の画像範囲を修正。
- 未設定だった unit_051〜unit_150 の100キャラに画像を生成。10枚のWebPアトラスをIDごとのSVG表示範囲で切り抜く。新規画像は各キャラ1種類を全レアリティで共用。既存60キャラの480画像は実ファイルのアルファ範囲を利用。
- キャラ画像の読込失敗時には既存静的画像、次に属性アイコンと名前を表示。
- パーティのリーダー整合性、ユニットID衝突、負数・非有限値の支払い、不正なアイテム数量、長押し強化の終了処理、解放・進化時の最新状態確認を修正。
- 初回無料ガチャのスキップ後に演出が再開する問題、開封の連打、画面離脱後のタイマー、重複キャラの結晶未付与を修正。動きを減らす設定にも対応。

## 検証

- `npm test`: 5項目成功。全160キャラ×8レアリティの実ファイル・画像範囲も検証。
- `npm run test:ui`: 390px／1440px ×17画面、計34表示で横はみ出し・読込済みimgの欠損・未処理JavaScriptエラーなし。検索、クリア、メニューとEscape、キーボードでのキャラ選択、初回召喚のスキップ、重複結晶付与、動きを減らす設定を確認。
- TypeScriptプロジェクト全体、Oxlint成功。Prisma生成と本番Vite/PWAビルド成功。
- ビルドの既存の500KB超バンドル警告は残る。

ブラウザ検証はテスト専用のローカル状態とAPIモックを使用。本番DBへの保存、認証、課金、対人戦・ギルド等のサーバー連携、全戦闘シナリオ、Safari/iOS実機は未検証。すべての潜在バグがなくなったことを保証する検証ではない。

## 再現

```sh
npm ci
npm test
npx playwright install chromium
npm run test:ui
npm run lint
npm run build
```

任意のChromiumは `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` で指定可能。日本語フォントのないCIでは、テスト用 `@fontsource/noto-sans-jp` のフォルダを `QA_FONT_DIR` に指定できる。フィクスチャは `tests/ui/fixture.html` にあり、本番エントリーから参照しない。出力は `test-results/`。

画像の実ファイルを更新した場合は `node scripts/build-image-manifest.mjs` で表示範囲一覧を再生成する。生成アトラスの登録は `scripts/import-generated-art.mjs`、生成仕様は `docs/character-art-prompts.json` を参照。
